# CargoPlanner

## Цель проекта

Одностраничное веб-приложение (SPA) для 3D-планирования загрузки грузовых автомобилей. Логист или диспетчер задаёт список грузов и автомобиль, приложение автоматически строит оптимальную раскладку в трёх режимах (вдоль, поперёк, смешанный), визуализирует её в 3D и 2D, позволяет настраивать зазоры и штабелирование, экспортировать отчёты (PDF, PNG, Excel) и сохраняет все настройки локально в браузере. Все расчёты выполняются на устройстве пользователя, данные не покидают браузер.

## Основные возможности

### Планирование загрузки

- **Цель:** Задать список грузов и автомобиль и получить готовую раскладку с метриками.
- **Описание:** Таблица грузов (прямоугольные и цилиндрические) с добавлением, редактированием и удалением. Выбор автомобиля из пресетов (ГАЗель, Бычок, ЗИЛ, КамАЗ, Фура) или создание собственного кузова с произвольными размерами. Автораскладка для трёх режимов (вдоль, поперёк, смешанный) с выбором лучшего по заполнению объёма.
- **Критерии приёмки:**
  - Пользователь может добавить, отредактировать и удалить грузы (прямоугольные и цилиндрические).
  - Пользователь может выбрать автомобиль из пресетов или создать собственный.
  - Для каждого из трёх режимов рассчитывается раскладка и выбирается лучший вариант по заполнению объёма.
  - Отображаются метрики: количество размещённых/всего грузов, заполнение объёма и веса (%), общий вес, свободные объём и вес, габариты укладки, возможность штабелирования, список неразмещённых грузов.

### 3D-визуализация

- **Цель:** Наглядно увидеть результат раскладки в интерактивном 3D-кузове.
- **Описание:** Интерактивная 3D-сцена: вращение, зум, панорамирование. Полупрозрачный кузов автомобиля. Каждый груз — цветной параллелепипед или цилиндр с подписью при наведении. Управление видимостью слоёв по высоте. Клик выделяет груз (камера при этом не наводится). Негабаритные грузы помечаются знаком «⚠».
- **Критерии приёмки:**
  - 3D-сцена рендерит кузов и все размещённые грузы с цветовой кодировкой.
  - Доступны вращение, зум и панорамирование сцены.
  - При наведении на груз показываются его параметры.
  - Есть кнопки управления видимостью слоёв по высоте.
  - Клик по грузу выделяет его (без наведения камеры).

### 2D-вид сверху

- **Цель:** Дополнительно посмотреть раскладку сверху послойно.
- **Описание:** 2D-схема видом сверху — основной вид приложения (2D по умолчанию, переключение на 3D): границы кузова, грузы-прямоугольники с подписями, пунктирная рамка зазоров от стен (если зазоры включены и возможны). Размерные подписи кузова: длина — сверху/снизу по центру, ширина — слева/справа по центру. Грузы можно перетаскивать мышью с проверкой границ кузова (выход за пределы отклоняется с тостом) и коллизий только в пределах одного слоя (пересечение с грузом на другом слое не считается конфликтом; на том же слое подсвечивается и отклоняется с тостом «Пересечение с грузом»). Выбранный груз можно переместить на другой слой через поле ввода высоты с проверкой коллизий и высоты кузова. Клавиатурные шорткаты: стрелки — перемещение выбранного груза, PageUp/PageDown или +/− — смена слоя. Есть управление видимостью слоёв и всплывающая легенда управления.
- **Критерии приёмки:**
  - 2D-схема отображает кузов и грузы сверху с подписями.
  - При включённых зазорах рисуется пунктирная рамка зазоров (не выходящая за пределы кузова).
  - Пользователь может перетаскивать грузы с проверкой границ и коллизий (в пределах слоя).
  - Пользователь может менять слой груза в 2D (мышью и с клавиатуры).
  - Пользователь может переключаться между 2D и 3D видами (2D — по умолчанию).

### Зазоры и штабелирование

- **Цель:** Учесть зазоры между грузами и стенами и настроить многослойную укладку.
- **Описание:** Три типа зазоров — от стен (`gapWalls`), между рядами по ширине (`gapWidth`), между рядами по длине (`gapLength`) — задаются в мм, применяются к раскладке, сохраняются отдельно для каждого режима. Валидация: значение не превышает максимально допустимое (`findMaxGapByType`, который учитывает размеры грузов и габариты кузова), при превышении — откат и тост; отрицательные значения запрещены; при смене авто/режима зазоры обрезаются до максимума с тостом. Штабелирование: поле «Максимальное количество слоёв» (по умолчанию 1) вместо ограничения высоты — высота автоматически ограничена кузовом; максимум слоёв = `floor(высота кузова / высота самого низкого груза)`, при попытке ввести больше — откат и тост. Укладка учитывает опору (`stackable`), совместимость (прямоугольный на прямоугольный, цилиндр на цилиндр той же ориентации, группа совместимости) и максимальную нагрузку сверху (`maxLoad`).
- **Критерии приёмки:**
  - Пользователь может включить зазоры и задать три значения, которые применяются к раскладке.
  - Значения зазоров сохраняются отдельно для каждого режима и восстанавливаются при переключении.
  - Недопустимые значения (отрицательные или превышающие максимум) отклоняются с подсказкой.
  - Пользователь задаёт максимальное количество слоёв, грузы укладываются в слои с учётом опоры, совместимости, нагрузки и высоты кузова.

### Умный подбор автомобиля

- **Цель:** Автоматически подобрать подходящий автомобиль под текущий список грузов.
- **Описание:** Модальное окно со списком всех доступных автомобилей (пресеты и пользовательские). Для каждого — статистика: количество размещённых грузов, заполнение объёма и веса, габариты укладки, возможность штабелирования. Настраиваемая сортировка (по объёму/весу/габаритам — возр./убыв., по количеству размещённых). Если груз не помещается ни в одном из режимов, он выделяется жёлтым в списке «Не помещаются», а автомобиль помечается жёлтым бейджем «Не подходит для N грузов». Кнопка «Выбрать» применяет автомобиль и пересчитывает раскладку. Есть прокрутка списка.
- **Критерии приёмки:**
  - Пользователь может открыть подбор и увидеть всех доступных автомобилей со статистикой по текущим грузам.
  - Варианты отсортированы по заполнению объёма.
  - Выбор автомобиля применяется и пересчитывает раскладку.

### Экспорт отчётов

- **Цель:** Выгрузить результаты планирования в PDF, PNG и Excel.
- **Описание:** PDF — параметры авто, метрики, зазоры, список грузов, 2D-схемы по слоям, инструкция для грузчиков. PNG — снимок текущего активного вида (2D или 3D) с наложенными метриками. Excel — параметры, грузы, зазоры, все варианты раскладки (вдоль/поперёк/смешанный).
- **Критерии приёмки:**
  - PDF-отчёт включает параметры авто, метрики, зазоры, список грузов и инструкцию для грузчиков.
  - PNG-снимок захватывает текущий активный вид (2D или 3D) вместе с метриками.
  - Excel-файл содержит параметры, грузы, зазоры и все варианты раскладки.

### Локализация, единицы и тема

- **Цель:** Адаптировать интерфейс под язык, единицы измерения и оформление.
- **Описание:** Полная локализация на русский и английский. Переключение единиц длины (мм/см/м) и веса (кг/т). Тёмная и светлая темы.
- **Критерии приёмки:**
  - Пользователь может переключать язык интерфейса (русский/английский) без потери данных.
  - Пользователь может переключать единицы длины (мм/см/м) и веса (кг/т), значения пересчитываются корректно.
  - Пользователь может переключать тёмную и светлую тему.

### Сохранение состояния

- **Цель:** Не терять настройки, пресеты, грузы и раскладку между сессиями.
- **Описание:** Настройки интерфейса (язык, единицы измерения, тема) сохраняются мгновенно. Автомобиль, грузы, пользовательские пресеты и штабелирование сохраняются вручную через единую кнопку «Сессии», которая открывает диалог с двумя вкладками: «Сохранить» (ввод имени + сохранение) и «Загрузить» (список сессий с датами, загрузкой и удалением). После сохранения — уведомление «Сессия «Имя» сохранена». Список сессий хранится в localStorage (ключ `mlp:sessions`), максимум 50 сессий. Удаление подтверждается диалогом. Зазоры между сессиями не сохраняются — при загрузке сессии сбрасываются к нулю; в рамках одной сессии они хранятся отдельно для каждого режима (along/across/mixed).
- **Критерии приёмки:**
  - Язык, единицы и тема восстанавливаются сразу после перезагрузки.
  - Пользователь может сохранить сессию с именем и загрузить/удалить любую из списка.
  - Зазоры при загрузке сессии сбрасываются, в рамках сессии хранятся per-mode.

### Пресеты автомобилей и грузов

- **Цель:** Быстро добавлять стандартные грузы и кузова.
- **Описание:** Стандартные пресеты автомобилей (ГАЗель Бизнес, ГАЗель NEXT, Бычок/ГАЗ-3309, ЗИЛ-5301, КамАЗ-4308, КамАЗ-65117, Еврофура 20 т, Jumbo) с реальными размерами доступны в выпадающем списке и через диалог «Пресеты авто». Диалог «Пресеты авто» позволяет выбрать авто, а также добавить/редактировать/удалить пользовательские автомобили. Встроенные пресеты нельзя удалять, но можно редактировать (изменённая версия сохраняется как пользовательский пресет с пометкой «изменён») и сбрасывать к дефолту. Стандартные пресеты грузов (европаллет, финпаллет, бочка 200 л металл/пластик, ящик стандартный, мешок 50 кг, рулон) управляются через диалог «Пресеты»: встроенные — редактируются (сохраняются как «изменён» и сбрасываются), пользовательские — добавляются/редактируются/удаляются. Можно сохранить текущий груз как пресет и добавлять, редактировать и удалять собственные кузова.
- **Критерии приёмки:**
  - Доступны стандартные пресеты авто в выпадающем списке и пресеты грузов с реальными значениями.
  - Пользовательские пресеты грузов можно добавлять, редактировать и удалять через диалог «Пресеты».
  - Собственные кузова можно добавлять, редактировать и удалять.

## Дополнительные заметки

- Все расчёты выполняются в браузере; данные не передаются на сервер.
- Негабаритные грузы (isOversize) могут выходить за габариты кузова; ставятся на пол кузова, визуально выделяются (пунктирная обводка, знак «⚠»), учитываются отдельно в метриках («Размещено обычных: X, негабарит: Y») и сопровождаются подсказкой о проверке возможности перевозки. Обычные грузы никогда не выходят за пределы кузова, включая контроль высоты на каждом шаге упаковки.
- Подсказки по загрузке: малое заполнение объёма (<50%), неразмещённые грузы, вес близко к пределу (>85%), свободное место для следующего слоя. Подсказка о слое N появляется только если штабелирование включено, пользователь ещё не указал достаточно слоёв (maxLayers < N), в раскладке остались грузы для нового слоя и высоты кузова хватает. При включённых зазорах в подсказке о неразмещённых грузах добавляется фраза «или уменьшите зазоры».
- Глобальные ограничения числовых полей: автомобиль (длина 1500–53500 мм, ширина 1200–10000, высота 300–8000, грузоподъёмность 0–500000 кг, где 0 = не ограничена) и груз (длина 100–53500, ширина 100–10000, высота 100–8000, диаметр 100–9500, вес 10–500000, количество 1–10000, макс. нагрузка 0–500000). Ввод вне диапазона отклоняется через общую функцию `validateField`. Габариты груза не могут превышать кузов (кроме isOversize). При превышении суммарного веса над грузоподъёмностью — предупреждение (тост), но продолжить разрешено. Максимально допустимые зазоры вычисляются отдельно для каждого режима с учётом размеров грузов (`findMaxGapByType`).
- CSV-импорт: каждая строка проходит валидацию, некорректные строки отбрасываются с уведомлением о количестве пропущенных.
- Упаковка до 100 грузов должна выполняться быстро (менее 1 секунды).
- Интерфейс корректно отображается на экранах от 1024px.
- Базовые ARIA-атрибуты для интерактивных элементов.
- Настроен экспорт в CSV (импорт/экспорт грузов).
